## 后续一起更新的流程

1. 先确认事实：核对 [facts.md](facts.md) 与 [CV](../../content/cv.md)，遇到冲突回到用户最新确认，不从推荐文案推断新事实。
2. 若定位改变，先改 [positioning.md](positioning.md)，再核对各平台文本；不要自动把研究兴趣写成已完成的项目。
3. 同次检查 LinkedIn、ORCID、Scholar、短版与口头介绍，以及 [首页/CV 对照](website-cv.md)。需要改动的文件一起提交；无需改动的标为“无变化”。
4. 外部平台需另行实际更新。仅修改这些 Markdown 文件不等于更新了账号；记录平台实际修改日期，未经检查保持“未核验”。
5. 核对具体职称、日期、学位、DOI 与项目链接；网站源文件变动时构建 Hugo，并验证上线结果。
