## OMSA Method Map

OMSA is not presented here as a separate course portfolio. It is the methods layer underneath my research-backed portfolio: healthcare analytics, clinical NLP, statistical learning, visualization, simulation, and end-to-end project delivery.

| Method Area | OMSA Courses | How I Apply It | Public Artifact |
|---|---|---|---|
| Healthcare Data Science | CSE 6250 Big Data Analytics for Healthcare | EHR-based modeling, healthcare utilization prediction, clinical cohort thinking. |  |
| Clinical NLP | CSE 8803 Natural Language Processing | Clinical text representation, note-level vs encounter-level labels, NLP model evaluation. |  |
| Statistical and ML Foundations | ISYE 6740 Computational Data Analytics; ISYE 8803 High-Dimensional Data Analytics | Prediction modeling, feature selection, validation, regularization, high-dimensional clinical and environmental data. |  |
| Visualization and Communication | CSE 6242 Data and Visual Analytics | Cohort dashboards, system analytics, model explanation, interactive communication. |  |
| Decision and Workflow Modeling | ISYE 6644 Simulation; MGT 8803 Business Fundamentals for Analytics | Clinical workflow simulation, stakeholder framing, analytics-to-decision translation. |  |
| End-to-End Project Delivery | CSE 6748 Practicum | Scoping, implementation, evaluation, documentation, and presentation of applied analytics systems. |  |

### Principle

Coursework should not be displayed as isolated assignments. Each method should eventually connect to a research question, reusable workflow, public note, or portfolio asset.
