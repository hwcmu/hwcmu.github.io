### Near-Term Build Priority

1. **Clinical Model Evaluation Toolkit**  
   A compact repository with synthetic data examples, reusable evaluation functions, calibration plots, threshold analysis, and a report template.

2. **Clinical NLP Field Notes**  
   A method-note repository rather than a raw notebook dump. The first essay should be: *Clinical NLP Is Not Just Text Classification*.

3. **AI Research Workflow Lab**  
   A long-term home for reproducible research workflows that connect clinical analytics, biostatistics, writing structure, and AI-assisted review.

### Quality Standard for Each Public Asset

Each public repository or portfolio asset should include:

- Clear purpose
- Example input and output
- Method explanation
- Limitations
- Connection to research or clinical workflow
- License or citation note
- Reproducible structure where possible
